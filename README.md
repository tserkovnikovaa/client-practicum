# Практика между встречами

Небольшой сайт Анастасии Церковниковой с домашними заданиями для клиентов психологической практики.

- Главная страница: `index.html`
- Первое упражнение: `tasks/diary.html`
- Дневник: 7 дней, выбор эмоций, шкалы, автосохранение в localStorage, экспорт в PDF через браузер.
- Сайт не получает записи: они остаются в браузере на устройстве клиента.
- Если несколько человек используют один браузер, они могут увидеть записи; очистка данных браузера удаляет сохраненное.
